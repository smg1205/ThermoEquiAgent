# 模型路由

路由先施加**硬性排除**，再使用一个可解释的评分，由以下要素构成：相态支持、体系契合度、工况、参数可得性、证据质量、外推惩罚与数值风险。Wilson 被排除在 LLE 之外。电解质被拒绝。近理想低压 VLE 优先 Ideal/Wilson，极性非理想低压 VLE 优先 NRTL/UNIQUAC，高压烃类优先 Peng-Robinson。**必需但缺失的参数集会令候选模型不可执行。**

执行阶段另有一道保守的后端闸门。用户显式指定的模型会被保留，但仍须通过后端适用性检查。未指定模型时，闸门会考察压力、是否有经过审核的本地 Ideal/Raoult 纯组分性质，以及体系是否属于当前 Peng-Robinson 适配器支持的烃类 / 白名单轻气体集合。不支持的缔合体系会**直接失败**，而不是被送进 PR。LLE 绝不猜测：在具备经审核的 NRTL 或 UNIQUAC 参数集与生产后端之前，它返回 `missing_parameters`。Peng-Robinson 还要求每一对二元组分都有 ChemSep PR 交互条目；适配器**不会**用 0 悄悄替换缺失值。所选模型与规则原因会持久化到输入快照中。
