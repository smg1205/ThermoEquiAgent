# 参数证据

每个参数集都会记录：组分顺序、形式、单位、适用范围、相平衡类型、来源标题 / 标识 / 类型、质量与备注。允许的无引用来源类型为 `user_supplied`、`test_fixture`、`estimated` 和 `unknown`。**`test_fixture` 会被生产仓库的写入拒绝。** 反转组分顺序时必须显式变换有方向性的参数。

公开 schema 会拒绝以下情形：重复或空白的组分标识、为空或非有限的参数值、不完整的单位映射，以及非正或反向的适用范围。文献与数据库记录必须同时提供来源标题和标识。参数集标识不可变；重复的生产写入返回 `409 duplicate_parameter_set`，而**不会覆盖**原始记录。
