# DWSIM 复现与验证手册：两个真实 VLE 实验案例

> 目的：用 DWSIM（NRTL/UNIQUAC 等严格活度模型）复现两个**真实 VLE 实验体系**的泡点数据，
> 与 `docs/` 下 Excel 里的实验实测值比对。数据来自 `binary_vle_english.xlsx` 与
> `ternary_vle_english.xlsx`（均有 DOI 溯源），本身就是物理合理的实测泡点。
>
> 这是"用严格模拟验证实验数据 / 交叉核对"的方法，与 `lunwen/` 三篇论文"用严格模拟当基准"一致。

| | 案例 1（二元） | 案例 2（三元） |
|---|---|---|
| 体系 | **乙醇–乙酸乙酯** | **乙醇–环己烷–丙酸乙酯** |
| 数据文件 | `docs/BubbleData_case1_ethanol_ethylacetate_760.csv` | `docs/BubbleData_case2_ethanol_cyclohexane_ester_760.csv` |
| 数据点数 | 41 | 124 |
| 压力 | 常压 760 mmHg | 常压 760 mmHg |

## 1. DWSIM 通用建模步骤（两案例共用）

1. **新建流程**：打开 DWSIM → New Simulation（空模板即可）。
2. **添加组分**：主界面"组分 / Compounds"→ 添加：
   - 案例 1：`Ethanol`、`Ethyl acetate`
   - 案例 2：`Ethanol`、`Cyclohexane`、`Ethyl propionate`
3. **选热力学模型**：这些体系非理想性强（尤其乙醇-乙酸乙酯有共沸、案例 2 含醇+酯+环己烷），
   用**活度系数模型**：建议 **NRTL**（首选）或 **UNIQUAC / Wilson**。避免用 Peng–Robinson 等 EOS。
4. **建闪蒸单元（Flash）**：拖入一个 **Flash**（气液两相单级平衡）。进料物流 → Flash → 气相、液相两股出流。
5. **跑模拟**：计算。
6. **读泡点**：从 Flash 出流读**温度、压力、汽/液相摩尔组成**。

> 更直接：在**物流（Material Stream）**里给液相组成 + 压力（760 mmHg），DWSIM 自动给出泡点温度
> 与汽相组成。若版本提供 "Phase Envelope / Bubble & Dew" 分析工具，可直接生成 T–x–y 曲线。

## 2. 案例 1：乙醇–乙酸乙酯（二元，等压泡点 @ 760 mmHg）

数据为**等压 T–x–y**：给定压力 760 mmHg，每个液相组成 x_乙醇 → 泡点温度 T 与汽相组成 y_乙醇。

在 DWSIM 里任选若干组成点（建议至少 6–8 个点，覆盖共沸附近），对每个 x 记下
**泡点温度 T** 与 **汽相组成 y_乙醇**，填入下表并与 `BubbleData_case1_*.csv` 的实验值比对：

|---|---|---|---|---|---|---|
| 0.10 | | | | | | |
| 0.30 | | | | | | |
| 0.50 | | | | | | |
| **0.62（共沸附近）** | **71.8** | | | | | |
| 0.80 | | | | | | |
| 0.95 | | | | | | |

> **关注点**：乙醇-乙酸乙酯最低沸点共沸（≈71.8 °C，x_乙醇≈0.56–0.62）。DWSIM 若用 NRTL 且参数来自

## 3. 案例 2：乙醇–环己烷–丙酸乙酯（三元，等压泡点 @ 760 mmHg）

数据为等压 T–x–y；每个点给 x_乙醇、x_环己烷（丙酸乙酯 = 1 − x_乙醇 − x_环己烷）→ 泡点温度 T 与汽相组成 y。

在 DWSIM 里对若干三元组成点复现。示例点（取自导出数据）：

| x_乙醇 | x_环己烷 | x_丙酸乙酯 | T_实验(°C) | T_DWSIM | ΔT | y_乙醇(实) | y_乙醇(DWSIM) |
|---|---|---|---|---|---|---|---|
| 0.464 | 0.498 | 0.038 | 66.4 | | | 0.457 | |
| 0.228 | 0.156 | 0.616 | 83.8 | | | 0.444 | |
| 0.271 | 0.235 | 0.494 | 74.? | | | 0.433 | |

> 组成归一：CSV 里 x_丙酸乙酯、y_丙酸乙酯 = `1 − x_乙醇 − x_环己烷`（及对应 y），DWSIM 里三者全部填入。

## 4. 数据质量说明（如实标注）

- **案例 1（乙醇-乙酸乙酯）**：Excel 标记第一个热力学一致性复核为通过（quality_check_1=1），数据可靠。
- **案例 2（乙醇-环己烷-丙酸乙酯）**：三条数据均来自单一文献 DOI（`10.1016/j.fluid.2018.07.013`），
  常压、组成归一正确、T–P 合理；但 Excel 的三元一致性复核标记多为 0/-1（未显式通过）。
  → 用 DWSIM 独立复现恰好能**交叉验证**这个三元数据是否物理自洽：若 DWSIM（NRTL/UNIQUAC）能在多数点
  复现 T（ΔT ≤ 1–2 K），说明数据可信；若在某组成偏差明显，可能该点有测量误差，可剔除或复核。

---

## 5. 判断"是否符合物理定律"

| 检查 | 物理合理判据 | 若违反应复核 |
|---|---|---|
| 泡点温度随重组分含量升高 | T 随重组分（高沸点）↑而↑ | 反向跳变 |
| 纯组分端点 | x→1 纯乙醇 T→沸点(≈78.4°C) | 端点不收敛 |
| 共沸（案例1） | T–x 曲线有最低点 | DWSIM 与实验不吻合 |
| 汽相归一 | Σy=1 | 组成未归一 |
| DWSIM vs 实验 | ΔT ≤ 1–2 K，Δy ≤ 0.02–0.05 | 偏差大需复核数据 |
