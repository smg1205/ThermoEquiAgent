# 萃取精馏 DWSIM 文件使用指南

本文档说明 ThermoEqui-Agent 导出的萃取精馏塔 `.dwxmz` 文件里已经有什么、还差什么，
以及如何在 DWSIM 图形界面里补上最后一步、让塔能够计算。

## 1. 导出文件里已经包含什么

导出的 `Extractive Distillation Column` 文件已经就绪的部分：

| 项目 | 已设置 |
|------|--------|
| 塔类型 | 严格塔 `DistillationColumn`（rigorous column） |
| 组分 | 乙醇、水、萃取剂（DWSIM 规范名） |
| 物性包 | 按设计的物性包（如 NRTL） |
| 进料流 | `Ethanol Water Feed` → 塔进料口（进料板） |
| 萃取剂流 | `Entrainer` → 塔第二进料口 |
| 塔顶产品 | `Ethanol Product`（馏出液） |
| 塔釜产品 | `Water Entrainer Bottoms`（塔底） |
| 塔板数 | 按设计（如 12 块） |
| 回流比 | 按设计（如 2.772） |

也就是说，**物料连接和基本塔参数都已配置好**，打开 DWSIM 就能看到结构完整的流程图。

## 2. 为什么还需要一步（限制说明）

DWSIM 的严格塔 `Validate()` 除了物料连接外，还要求**塔内部的求解规格**齐全，例如：

- 冷凝器（全凝器）的**规格**（用回流比 / 馏出流量 / 纯度等来指定塔顶）
- 再沸器的**规格**（用再沸比 / 塔釜流量 / 热负荷等来指定塔釜）

这些**塔内部规格**在 DWSIM 的 Automation API 上没有稳定、可靠的设置接口，属于打开后由
用户在塔参数界面配置的内容。因此导出的文件能生成、连接正确，但**首次计算前需在 DWSIM 里
补一条冷凝器和再沸器的规格**。请按第 3 节操作。

> 这是 DWSIM Automation 的能力边界，不是本项目代码的 bug。下游导出器（DWSIM）要求完整
> 求解结构，而该结构只能在 GUI 中完备指定。

## 3. 在 DWSIM 里让塔可计算（步骤）

假设你已经打开导出的 `.dwxmz` 文件。

### 步骤 A：确认流程图连接完整

1. 在 DWSIM 画布上查看 `Extractive Distillation Column` 塔。
2. 应能看到 4 条物料连接线：
   - `Ethanol Water Feed` → 塔（进料）
   - `Entrainer` → 塔（萃取剂，第二个进料口）
   - 塔 → `Ethanol Product`
   - 塔 → `Water Entrainer Bottoms`
3. 如果任一缺失，用工具栏的连接工具（铅笔/导线图标）补上。

### 步骤 B：给冷凝器加规格

1. 双击塔，打开塔的配置窗口（Column Configuration）。
2. 找到 **Condenser（冷凝器）** 页。
3. **Condenser Type** 应保持 **Total Condenser**。
4. 在 Specification（规格）区，选择一种指定方式并填值，例如：
   - **Reflux Ratio = 2.772**（用设计回流比），或
   - **Distillate Flow Rate**（给定塔顶产量）。
5. 应用。

### 步骤 C：给再沸器加规格

1. 在同一个塔配置窗口，找到 **Reboiler（再沸器）** 页。
2. 在 Specification（规格）区，选择一种指定方式并填值，例如：
   - **Boilup Ratio**（给定一个接近 1 的初始估计，再微调），或
   - **Bottoms Flow Rate**（给定塔釜产出量），或
   - 直接给定一个 **Reboiler Duty** 初始估计。
3. 应用。

### 步骤 D：接上能量流（可选但推荐）

严格塔计算时需要冷凝器和再沸器的热负荷（duty）：

1. 在对象面板找到 **Energy Stream**（能量流，个别版本叫 Utility/Heat）。
2. 放一个能量流对象在**塔顶冷凝器**附近，用连接工具从**冷凝器能量接口**连到它。
3. 再放一个能量流对象在**塔釜再沸器**附近，从**再沸器能量接口**连到它。
4. （若按步骤 B/C 用比值/流量规格指定，能量流可以自动算出负荷；若画面看不到能量接口，
   也可省略，DWSIM 用默认 duty 估计。）

### 步骤 E：运行计算

1. 点击 DWSIM 的 **Calculate / Run / Solve**（或 F5）。
2. 若仍提示缺连接，回到步骤 A/B/C 检查是否有端口未配对。

## 4. 预期结果

补全冷凝器/再沸器规格后，严格塔应能通过 `Validate()` 并开始迭代求解，得到塔顶塔釜组成、
温度、各模块热负荷等结果。设计参数（塔板数、回流比）已写入文件，可作为初始值。

## 5. 常见问题

- **提示 `One or more of the stream connections to the column is missing`**
  通常是冷凝器/再沸器规格或能量连接未补齐。按第 3 节 B/C/D 检查。
- **看不到能量接口 / 能量流**
  缩小画布缩放看塔图标边缘；或在对象面板搜索 "Energy" / "Utility"。
- **想用简捷塔（ShortcutColumn）快速估算**
  简捷塔能直接算出最小塔板/回流数，但只支持单进料（无法表达"进料+萃取剂在不同塔板"的
  真实萃取结构）。本项目导出使用严格塔以保持萃取结构的正确性。

## 6. DWSIM 版本确认

本指南针对 DWSIM 桌面版。不同小版本菜单措辞可能有差异（如 "Reboiler Duty" 位置不同），
但思路一致：**补冷凝器规格 + 补再沸器规格 + 接能量流 + 计算**。
