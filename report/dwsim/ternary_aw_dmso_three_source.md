## 要点说明

- **DWSIM 的汽相组成预测显著优于 ThermoFormer**：0.0714 vs 最佳权值 0.2233，
  好约 **3.1 倍**。这与报告 §2.2 原体系（1-丁醇 / 水 / 甲苯）的结论**方向相反**
  ——那里是 TF (0.0388) 优于 DWSIM (0.1183)。
- **ThermoFormer 的失效集中在 DMSO 与水**：最佳权值（seed_4）下 DMSO 分量
  MAE 0.2702、水 0.3349，而乙酸仅 0.0647。
  逐点看，TF 的 `y_DMSO` 随液相 DMSO 上升得**过快**：x_DMSO 从 0.405 升到 0.694 时，
  实验 `y_DMSO` 从 0.050 升到 0.529，而 TF 预测从 0.383 直接冲到 0.816
  （富 DMSO 端高估约 0.29）。反之 DWSIM 的 `y_DMSO` 从 0.016 升到 0.337，
  始终低于实验值（富 DMSO 端低估约 0.19）。
- **乙酸组分两边都准**：DWSIM 0.0207、TF seed_2 0.0459。
- DWSIM 温度系统性偏低 6~15 K，与组成误差方向不一致，源于 UNIFAC 基团贡献法
  对强缔合组分（乙酸、DMSO）的处理偏保守。

## 物性包选择（重要）

**本节 DWSIM 列必须使用 UNIFAC，不能用 NRTL。**

实测（本机 DWSIM）：乙酸/水、乙酸/DMSO、水/DMSO 这三对**都没有内置 NRTL
二元交互参数**，DWSIM 会走 `EstimateMissingInteractionParameters` 估算，
且 α 一律取默认值 0.2：

```
Estimated NRTL IP set for Acetic acid/Water:              -189.10 / 728.84 / 0.2
Estimated NRTL IP set for Acetic acid/Dimethyl sulfoxide: -1233.93 / -1295.15 / 0.2
Estimated NRTL IP set for Water/Dimethyl sulfoxide:       -1999.94 / -499.97 / 0.2
```

用这套伪参数算出的闪蒸完全失真，实测症状：
- 300 K（远低于所有组分沸点）即出现汽相
- 液相组成在 355~375 K 剧烈跳动，400~500 K 完全混乱
- 泡点二分收敛到搜索上界，温度偏差达 **+108 ~ +142 K**

对照：原体系（1-丁醇 / 水 / 甲苯）的三对**都**有内置参数，从不触发估算，
故原 §2.2 的 DWSIM 列（NRTL）是成立的。

UNIFAC 为基团贡献法，不需要二元交互参数，实测这三对均不触发任何
`Estimated ... IP set` 提示，相态行为随温度单调合理，故改用 UNIFAC。

## 泡点求解方法

固定 P 与总组成，二分温度，以 `PhaseIds` 判定相态：
`['Liquid']` 表示未到泡点，出现 `'Vapor'` 表示已越过泡点，
取刚出现汽相的温度。`PhaseIds` 是 DWSIM 判定相态的权威依据，
比按温度或组成猜相可靠（后者在本体系上曾导致错误结果）。

## 为什么换体系

原 §2.2 的 1-丁醇 / 水 / 甲苯 有一个根本问题：**该体系的萃取精馏不成立**。

- 选择性 `alpha_ext / alpha_base`，两源均 **< 1**（UNIFAC 0.7467、TF 0.8193），
  即萃取剂 1-丁醇**并未增强**水/甲苯的相对挥发度。
- 报告正文自己也承认，该案例宜表述为「**有萃取剂进料的三元精馏塔**」，
  而非依赖剂选择性的萃取精馏。

而本体系 乙酸 / 水 + DMSO：

| 判据 | 数值 | 结论 |
|---|---|---|
| 选择性 | **2.3731**（UNIFAC 6.4569） | > 1 ✅ 萃取剂确实增强分离 |
| alpha_base | 1.6836 | > 1 ✅ 关键对本就可分离 |
| 萃取剂沸点 | DMSO 463.7 K，三者最高 | ✅ 短节法假设成立 |
| 塔设计 | N=15, R=1.441（TF seed_2） | ✅ 工程可行 |

即这是一个**真正的萃取精馏体系**，作为报告案例比原体系更恰当。

**但需注意代价**：本体系 TF 的三元预测精度（MAE 0.2233 ~ 0.2871）
远差于原体系（MAE 0.0302），因为 DMSO 是强极性强缔合组分，
在 ThermoFormer 训练分布之外。若报告要同时体现「萃取成立」与
「TF 预测精度」，两个体系各占其一，无法兼得。
