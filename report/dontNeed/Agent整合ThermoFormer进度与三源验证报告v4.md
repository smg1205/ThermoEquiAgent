## 第一部分　模型集成（Agent + ThermoFormer + DWSIM）及流程展示

### 1.1 目标与约束

ThermoEqui-Agent 是一个对话式相平衡计算工作台：用户以自然语言提问，系统解析为任务并调用确定的计算核返回结果，必要时导出 DWSIM 文件。

工程约束：
- 大模型不参与数值计算，仅负责意图理解、工具选择与结果解释；数值来自 `thermo_engine` 并经独立校验。
- 模型不可用时退回规则/确定性计算。
- 缺少物性参数时返回缺参提示，不虚构数值。
- 明确拒绝的范围：电解质、聚合物、固液平衡、汽液液平衡、完整精馏塔设计。

### 1.2 Agent 编排

Agent 按"意图分流 + 有界执行"组织。入口为 `ConversationOrchestrator`（`orchestrator.py`），其 `chat()` 为主流程，`parse()` 供 API 使用。组件包括意图判断、任务构建（`providers.py`）、有界执行图（`graph_workflow.py`）、工具注册（`tools.py`）、对话记忆与知识问答、萃取导出（`extractive_distillation.py`）、模型选择（`router.py`）。

意图判断采用规则与模型交叉：规则先判（`DeterministicProvider`），模型不可用时信任规则；两者不一致时按可信来源取舍。

### 1.3 Agent整合ThermoFormer

模型在后端注册表 `thermo_engine/registry.py` 中与既有模型并列，经统一接口调用并做结果校验。

ThermoFormer 接入方式：编写后端类 → 声明能力 → 在注册表注册 → 加适用范围检查（组分数、压强、SMILES 上限）→ 结果经 `validate_equilibrium_result` → 权重延迟加载。

### 1.4 塔设计的 DWSIM 导出

萃取/精馏塔经确定性的塔设计（回流比、理论塔板、进料板/萃取剂板、塔顶/塔釜泡点温度）得到设计参数后，由 `thermo_engine/dwsim_export.py` 导出可加载计算的严格塔 `.dwxmz` 文件。塔的导出与算例分别见 §1.6 的两个下游案例：`export_generic_extractive_column`（带萃取剂的三元萃取精馏）与 `export_dwsim_binary_column`（二元普通精馏）；导出的塔能否在 DWSIM 中算出结果，以图形界面加载计算后结果页的状态为准。

**表 1.5-1　Agent 萃取精馏流程各阶段与所属模块**

|---|---|---|

#### 1.5.2　任务理解与路由

本阶段将自然语言请求转换为系统可执行的结构化任务描述（即 `TaskManifest`），不在本阶段执行任何平衡数值计算。

**LLM 的职能**：自请求文本中抽取待分离的轻组分与重组分、拟采用的第三组分萃取剂，以及各组分化学结构信息（包括名称、CAS 号与 SMILES，供 ThermoFormer 特征编码）；抽取分离目标（等压泡点温度 $T_b$、汽相摩尔组成 $y$）、操作条件（温度、压力、进料组成）、萃取剂流量比与塔顶所需纯度。当必需参数缺失，系统转入 `missing_parameters` 分支并显式报缺，不虚构数值或参数；当请求超出萃取精馏适用范围（如电解质、非均相体系）时依约束明确拒绝。

**Agent 的路由职能**：借助确定性后端注册表（`thermo_engine/registry.py`，含 `route_task` 与萃取模型路由）及相应 skills 完成路由，将任务指派至求解链，包括经典活度系数后端、免二元交互参数的 ThermoFormer 预测后端，以及用于后续独立校验的 DWSIM 严格求解。对第三组分（萃取剂）是否需要以及选哪一组分，依规则与预测后端判定，不依赖 LLM 直接给数值。

**阶段输出**：由于本阶段不具备数值求解能力，其为下一阶段提供完整的任务所需数据，包括组分顺序（轻组分、重组分、萃取剂之排布）、各组分的 SMILES、分离目标、操作压力与进料组成、萃取剂选型与流量比，以及拟调用的求解入口。

#### 1.5.3　相平衡求解：萃取体系的 ThermoFormer 预测

本阶段由 `thermo_engine` 选定热力学模型并完成求解，LLM 不参与平衡数值的直接计算。

**ThermoFormer 预测路径**：`thermo_engine/thermoformer_backend.py` 提供 `bubble_point` 等方法。给定压力 `pressure_kPa` 时输出泡点温度与汽相组成 $y$（等压工况）；给定温度 `temperature_K` 时输出泡点压力与 $y$（等温工况）。对含萃取剂的三元体系，依萃取段（重组分与萃取剂共存）与基础二元段分别读取泡点预测，得到无萃取剂时的相对挥发度与富萃取剂条件下的相对挥发度，其比值即剂的选择性。调用前须满足 ThermoFormer 适用范围约束：压力不超过 500 kPa、组分数不超过 3、且每一组分均须提供 SMILES；模型权重延迟加载，返回结果经 `validate_equilibrium_result` 校验。

**DWSIM 独立校验路径**：在萃取流程中，对体系相平衡与塔结果设定由 DWSIM 严格求解作为独立来源，经 `CalculateFlowsheet2` 等读取塔内/流股状态并比对，以交叉校验 ThermoFormer 与确定性引擎给出的泡点温度与汽相组成。

#### 1.5.4　塔设计与工程文件生成

用户在任务理解阶段或已选定的要求上给定分离体系、萃取剂及塔设计要求（如萃取剂流量比、进料位置、塔板起始选择）。塔体设计与参数计算采用确定性短节法（Fenske–Underwood–Gilliland，实际操作回流比取 1.4 倍最小回流比）：由 ThermoFormer 泡点反推出的相对挥发度（含剂选择性）代入 Fenske 求最小塔板、Underwood 求最小回流比，再以 Gilliland 关联得到理论塔板与操作回流比；塔顶、塔釜温度由 ThermoFormer 等压泡点预测给出。

随后将该设计经 `thermo_engine/dwsim_export` 导出为可在 DWSIM 图形界面加载计算的萃取精馏塔 `.dwxmz` 文件。塔能在 DWSIM 中算出结果的操作状态，以图形界面该塔结果页读数为准；本流程只给出结构与设计规格，不在文档内虚构塔的实测分布。

塔设计的确定性短节实现、进料约束与导出的可加载文件、以及经 DWSIM 计算所记录的操作点，详见 §1.6.2（萃取精馏塔案例）；其中使用的相对挥发度、塔板、回流比与温度数值得自上述流程的两种热力学来源（UNIFAC 或 ThermoFormer，见 §权值选择）。
