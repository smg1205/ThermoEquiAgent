# Research guide

ThermoFormer is a research codebase for reproducible vapor--liquid and liquid--liquid equilibrium studies.

Start with the [reproducibility guide](docs/reproducibility/README.md), then use the following resources:

- [Repository architecture](docs/architecture/repository_layout.md)
- [Experiment catalog](docs/reproducibility/experiment_map.md)
- [Dataset registry](datasets/README.md)
- [Checkpoint registry](models/README.md)
- [Scientific scope and manuscript alignment](docs/reproducibility/scientific_alignment.md)
- [Complete directory tree](docs/reproducibility/directory_tree.txt)

List registered experiments with `python scripts/run_experiments.py list`.
