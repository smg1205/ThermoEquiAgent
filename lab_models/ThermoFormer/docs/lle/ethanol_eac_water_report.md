# 乙醇 / 乙酸乙酯 / 水 三元 LLE — ThermoFormer 预测与实验对比

## 一、数据来源（可溯源）

`datasets/lle/ternary_lle.csv`，SMILES 顺序 `CCO | CCOC(C)=O | O`（乙醇/乙酸乙酯/水），
**57 条系线，6 个温度，3 个 DOI**：

| T (K) | 系线数 | DOI |
|---|---:|---|
| 283.15 | 7 | 10.1016/j.fluid.2005.08.009 |
| 298.15 | 14 | 10.1016/j.fluid.2005.08.009, 10.1021/je060054+ |
| 303.15 | 8 | 10.1016/j.fluid.2014.04.013 |
| 308.15 | 7 | 10.1021/je060054+ |
| 313.15 | 14 | 10.1016/j.fluid.2005.08.009, 10.1016/j.fluid.2014.04.013 |
| 318.15 | 7 | 10.1021/je060054+ |

数据覆盖**完整双节线**（同一温度下萃余相 EtOAc 从 0.001 到 0.075，萃取相 EtOAc 从 0.21 到 0.89）。

## 二、模型

`models/lle/prediction/ternary-system/seed_{0..4}/best.pt`（5 个种子，已训练），
经 `thermoformer.lle_tp.predict_verified.predict` 调用，纯结构输入 + T + P。

## 三、关键发现：预测输出的是整条双节线，不是一对端点

seed 0 在 298.15 K 返回 **24 组系线**（`pairs`），端点互不相同（L1 距离 1.615）。
它们构成完整的预测双节线：

```
pairs[0]   raffinate [0.0181, 0.0172, 0.9647]   extract [0.0356, 0.8075, 0.1570]
pairs[23]  raffinate [0.1111, 0.0536, 0.8353]   extract [0.1175, 0.3422, 0.5403]
```

**这一点很重要**：仓库里既有的 `ethanol_eac_water_tf_predictions.csv` 只取了 `pairs[0]`，
所以看起来"只有一个几乎不随温度变化的点"。实际上完整曲线是有的。

## 四、必须纠正的一个指标误读

预测器报告的 `equilibrium_rms` 在 **1e-16 ~ 1e-13**（float64 机器精度 2.2e-16）。

这**不是精度指标，而是求解器残差** —— 模型在自己的 Gibbs 面上把闪蒸解到了机器精度。
它**不能**说明预测与实验吻合。

`AGENTS.md` 对此有明确规定：

> A solver status alone is not physical validation. Check composition, material balance,
> equilibrium residuals, convergence, parameter applicability, and phase stability when relevant.

既有 CSV 里那列 `rms = 0.0` 就是这么来的，属于**误读风险**。

## 五、正确评估：按分支比最近邻

预测与实验都覆盖整条双节线，唯一合理的比法是**同分支最近邻 L1 距离**：

| T (K) | 萃取相 平均/最差 | 萃余相 平均/最差 |
|---|---|---|
| 283.15 | 0.0954 / 0.1479 | 0.0225 / 0.0520 |
| 298.15 | 0.0568 / 0.1079 | 0.0188 / 0.0572 |
| 303.15 | 0.0866 / 0.2692 | 0.0299 / 0.0400 |
| 308.15 | 0.0646 / 0.1380 | 0.0290 / 0.1056 |
| 313.15 | 0.0616 / 0.1182 | 0.0192 / 0.0285 |
| 318.15 | 0.0682 / 0.1383 | 0.0255 / 0.0939 |
| **总体** | **0.0722** | **0.0242** |

**萃余相（水相）预测明显更好（0.024），萃取相（酯相）偏差约为其三倍（0.072）。**

## 六、最严重的问题：种子间不一致

同一温度 298.15 K，5 个种子的 `pairs[0]` 首端点：

| seed | 萃取相 [乙醇, EtOAc, 水] | 萃余相 |
|---|---|---|
| 0 | [0.0356, **0.8075**, 0.1570] | [0.0181, 0.0172, 0.9647] |
| 1 | [0.0380, **0.8161**, 0.1458] | [0.0018, 0.0144, 0.9838] |
| 2 | [0.1322, **0.3989**, 0.4688] | [0.1246, 0.0255, 0.8499] |
| 3 | [0.1486, **0.2999**, 0.5515] | [0.1345, 0.0259, 0.8396] |
| 4 | [0.1328, **0.2949**, 0.5723] | [0.1218, 0.0202, 0.8581] |

**种子间 EtOAc 摩尔分数差异达 0.52**（0.29 ~ 0.82）。

对比：实验萃余相 EtOAc 全区间仅 0.001–0.075。
**种子分歧（0.52）远超实验数据的跨度。**

更要注意：seed 0/1 与 seed 2/3/4 明显分成两簇 —— 前者萃取相 EtOAc ≈ 0.81，
后者 ≈ 0.30。这不是随机噪声，是**两种不同的解**，说明模型学到了多解/不稳定行为。

## 七、结论

| 项 | 结论 |
|---|---|
| 数据 | ✅ 57 条系线，3 个 DOI，可溯源 |
| 预测是否存在 | ✅ 存在，24 条/温度，构成完整双节线 |
| 萃余相精度 | ⚠️ 可接受（L1 ≈ 0.024）|
| 萃取相精度 | ❌ 偏差偏大（L1 ≈ 0.072，最差 0.269）|
| 种子稳定性 | ❌ 不一致，EtOAc 分歧达 0.52，且分成两簇 |
| `equilibrium_rms` | ⚠️ 是求解器残差，**不可当作精度** |

**总体：模型能给出定性正确的液液分相（两个相的确分离、水相基本正确），
但酯相组成不可靠，且种子间不稳定。目前不宜用于定量设计。**

## 八、建议

1. **报告时只写按分支的 L1 距离**，不要引用 `equilibrium_rms` 作为精度。
2. **必须报告种子方差**，不能只展示 seed 0。
3. **用全部 5 个种子的中位数**做点估计，并给出分位区间。
4. 排查 seed 2/3/4 那一簇：是训练不充分，还是 Gibbs 面存在真多解。
5. 复用数据时注意 `pairs[0]` **只是双节线的一个端点**，不是"系统的 LLE 预测"。
